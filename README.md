# JavaScript Polyfills

Custom implementations of standard JavaScript methods and utilities.

## Polyfills Included

- **Function Methods:** `myCall.js`, `myApply.js`, `myBind.js`
- **Array Methods:** `myMap.js`, `myFilter.js`, `myReduce.js`, `myJoin.js`, `myPush.js`, `myPop.js`
- **Utilities:** `myDebounce.js`, `myThrottle.js`, `myMemoize.js`, `myOnce.js`

## Run

```bash
node <fileName>.js
